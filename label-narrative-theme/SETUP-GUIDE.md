# Quick Setup Guide - Label Narrative Theme

Get your label business website up and running in 30 minutes!

---

## 🚀 Quick Start (30 Minutes)

### Step 1: Install Theme (5 minutes)

1. Upload theme to WordPress
2. Activate the theme
3. Install and activate WooCommerce plugin
4. Complete WooCommerce setup wizard

### Step 2: Customize Your Brand (10 minutes)

Go to **Appearance → Customize** and update:

1. **Site Identity**
   - Upload your logo
   - Set site title: "Your Label Company Name"

2. **Theme Colors** (if needed)
   - Choose your brand colors
   - Or keep the default blue/green for trust and action

3. **Hero Section**
   - Update headline to match your unique value proposition
   - Change CTA button text if needed
   - Upload a background image (optional but recommended)

### Step 3: Configure Content (10 minutes)

Still in the Customizer:

1. **Your Story Section**
   - Replace default story with your brand narrative
   - Upload an image showing your labels or customers using them

2. **Benefits Section**
   - Keep defaults or customize to match your unique selling points
   - Make sure they're Australian-market focused

3. **Footer Settings**
   - Update copyright text
   - Add your contact details (email and phone)

### Step 4: Create Your Products (10 minutes)

1. Go to **Products → Add New**

2. Create your first product:
   - Title: "9×9cm Premium Labels"
   - Add compelling description
   - Set price
   - Upload product images

3. Set up attributes:
   - Shape: Square, Circle
   - Quantity: 50, 100, 250, 500
   - Finish: Glossy, Matte

4. Create variations with different prices for quantities

### Step 5: Create Menus (5 minutes)

1. Go to **Appearance → Menus**
2. Create a Primary Menu with:
   - Home
   - Products
   - About
   - Contact

## 📸 Photography Tips

### Product Photos You Need

1. **Hero Image**
   - Labels on actual products
   - Well-lit, professional looking
   - Shows scale and quality

2. **Detail Shots**
   - Close-up showing print quality
   - Texture and finish visible
   - Color accuracy

3. **Application Shots**
   - Labels being applied
   - Labels on various product types
   - Shows versatility

4. **Lifestyle Images**
   - Products with labels in use
   - Happy customers (with permission)
   - Australian settings if possible

### Quick Tips
- Use natural light when possible
- Keep background simple and uncluttered
- Show labels in context (on products)
- Include size reference (ruler, hand, common object)

## 🚢 Shipping Setup for Australian Business

### WooCommerce Shipping Zones

1. Go to **WooCommerce → Settings → Shipping**

2. Create shipping zones:

**Zone 1: Local (Your State)**
- Shipping Method: Flat Rate or Free Shipping
- Cost: $0-$5
- Delivery: 2-3 business days

**Zone 2: Australia-wide**
- Shipping Method: Flat Rate
- Cost: $8-$15 (adjust based on your costs)
- Delivery: 3-7 business days

**Zone 3: Remote Areas**
- Use postcode ranges
- Higher rates for remote locations

### Recommended Services
- Australia Post (most common)
- Sendle (good for small business)
- Startrack (for larger volumes)

## 💰 Pricing Strategy for Labels

### Volume-Based Pricing

```
50 labels:   $5.00 each = $250 total
100 labels:  $4.00 each = $400 total (20% discount)
250 labels:  $3.50 each = $875 total (30% discount)
500 labels:  $3.00 each = $1,500 total (40% discount)
1000 labels: $2.50 each = $2,500 total (50% discount)
```

### Pricing Psychology
- Always show the per-unit savings
- Highlight the most popular package
- Offer a "starter pack" for first-time customers
- Consider bundle deals (square + circle combo)

## 🆘 Common Issues & Solutions

### "My menu isn't showing"
1. Go to Appearance → Menus
2. Create a menu and add pages
3. Assign it to "Primary Menu" location
4. Save

### "Products aren't displaying on homepage"
1. Make sure you've created products
2. Products must be published (not draft)
3. Use the Products shortcode or widget
4. Check theme options for product display

### "Site is loading slowly"
1. Install WP Rocket or caching plugin
2. Optimize images (use Smush plugin)
3. Remove unnecessary plugins
4. Check with hosting provider

### "Mobile menu not working"
1. Clear cache
2. Check JavaScript isn't blocked
3. Disable conflicting plugins
4. Check browser console for errors
