# Evaluation set

Hand-labelled inputs used to score Pass 1 (vision classifier) and to spot-check
Pass 2 (sequencer). Built out in Phase 1 once the classifier exists; in Phase 0
this is just the skeleton.

## Layout

```
data/eval/
├── images/            # 30–50 photographer-curated select images
└── ground_truth/      # one JSON per image, matching the Pass 1 schema
```

## Conventions

- File names match between `images/` and `ground_truth/`: `wedding_001.jpg`
  pairs with `ground_truth/wedding_001.json`.
- Ground truth records are hand-written by a senior reviewer (Dylan), not
  generated by the model.
- Hero score distribution targets per spec §7: ~10–20% scoring 8+,
  ~30–40% scoring 6–7. If the eval set itself violates these bands, it is
  not representative of a curated select set and should be rebalanced.
- 3–5 hand-curated layout decisions for Pass 2 live alongside as
  `pass2_examples/<shoot_id>/{manifest.json, layout-expected.json}`.

## What lives where

Image rights: only use images you have explicit consent to retain. Public
domain or personally-owned shoots only. Do not check in client-delivered
images.
